# Amine Bennani — Portfolio

Personal portfolio: https://aminebennani.netlify.app/

React 19 + Vite 7, CSS Modules, no runtime backend. Built and deployed by Netlify (`npm run build` → `dist`).

## Development

```bash
npm install
npm run dev      # local dev server
npm run lint
npm run build    # production build in dist/
npm run preview  # serve the production build
```

## Content

- `src/data/projects.js` — featured projects and case studies
- `src/data/profile.js` — contact details, experience, education, skills, archive (`cvUrl` enables the CV download)
- `src/data/images.json` + `src/assets/work/` — responsive WebP screenshots taken from each project's repository
- `src/data/trajectories.json` — hero dataset, generated by `scripts/prepare_trajectories.py` from the synthetic fleet data in [gps-trajectory-analysis-seville](https://github.com/AmineBennani7/gps-trajectory-analysis-seville)
